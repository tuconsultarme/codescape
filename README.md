# CODESPCAPE

Integrantes: Bautista Kahr, Bruno Massaccesi, Salvador Soncini, Valentina Perie

En este trabajo realizado en el lenguaje de python, el usuario jugara una especie de Scape Room, el cual se basa en la historia de un chico que se queda encerrado en la UADE (Univerdidad Argentina de la Empresa) 

Se deberia ingresar con las credenciales ya propiuestas por el programa:
USUARIO: jugador
CONTRASEÑA: bruno
El programa cuenta con un sistema de encriptacion: CRIFRADO CESAR
El cual se basa en la tabla ASCII para la conversion de sus caracteres a valores respectivos de esta tabla. Ademas posee un desplazamiento de 3 unidades hacia la izquierda.
Todo hecho en la funcion: encriptar()

En la opcion menu podremos elegir diferentes opciones:

1- INSTRUCCIONES: Aqui se daran unas breves instrucciones para poder seguir y completar el juego

2- JUGAR: Te manda directamente a la primera de las dos salas que se pueden jugar para que empieces el desafio.

3- CAMBIAR CONTRASEÑA: En este apartado se podra cambiar la contraseña, sin embargo debe tener ciertos filtros para que pueda ser valida (especificadas en el programa).
